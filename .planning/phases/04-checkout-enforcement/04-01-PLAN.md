## Locked Decisions (from 04-CONTEXT.md — NON-NEGOTIABLE)

- **D4-01 remaining-credit:** block iff `exposure_cents + cart_total_cents > limit_cents`. At-limit exactly (sum == limit) is ALLOWED. Integer cents, never float.
- **D4-02 currency:** compare only when `cart.cost.totalAmount.currencyCode === payload.currency`; on mismatch skip the over-limit rule (fail open for that rule only) — the overdue block still applies (boolean, currency-independent). Never convert.
- **Research corrections binding here:** result shape is `operations[].validationAdd.errors[{message, target: "$.cart"}]`; metafield read omits the namespace argument (app-reserved namespace resolves); the Function input has no payment-method/terms selection — blocking a terms-bearing company's checkout IS the net-terms block.
