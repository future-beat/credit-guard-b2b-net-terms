# Plan 01-03 — GDPR compliance webhooks + two-stage uninstall lifecycle

## Phase Goal

Merchant can install the app into a deployed, review-compliant embedded admin shell. (Prose ROADMAP goal — see plan 01-01 note.)

<objective>
Add everything the template does NOT ship for compliance: the three mandatory GDPR webhook subscriptions + handler route (FOUND-02), and the D-06 two-stage uninstall lifecycle — deactivate-and-retain on app/uninstalled, hard-delete on shop/redact, reactivate on re-install (FOUND-03).
