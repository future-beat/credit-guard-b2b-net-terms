# Plan 01-01 — Walking Skeleton: scaffold, register, embedded shell end-to-end

## Phase Goal

Merchant can install the app into a deployed, review-compliant embedded admin shell.

> ROADMAP `**Goal:**` is prose, not user-story format. Per MVP-mode rules the planner does not invent a story; run `/gsd-mvp-phase 1` if story framing is wanted. This plan delivers the walking-skeleton slice of that goal: install → OAuth (managed) → embedded Polaris shell → session persisted to Postgres.

<objective>
Create the entire codebase from the official `shopify-app-template-react-router` scaffold, register the app against the Partner account, pin the Shopify API version to 2026-07 everywhere, swap the datasource to Postgres with an applied init migration, and replace the template home page with the UI-SPEC-locked "Credit Guard" shell (empty state, error boundary, single Home nav item, healthz route).

Purpose: This is the Walking Skeleton (Phase-1 tracer) — the thinnest path that proves Shopify platform → RR7 server → Prisma/Postgres → embedded Polaris UI all work wired together, before any compliance or deploy expansion. Every later phase builds on the seams created here (SKELETON.md records them).
Output: Working scaffold at repo root, installable on the dev store via `shopify app dev`, with build green and init migration applied.
</objective>
