## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Shopify → /webhooks/bulk-operations | Unauthenticated POST; could name an attacker-chosen operation or URL |
| App → JSONL result download | Outbound fetch of a URL that must originate from the Admin API only |
| Embedded admin loader → backfill trigger | Session-authenticated; must stay non-blocking and idempotent |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-12 | Spoofing | webhooks.bulk-operations.tsx | high | mitigate | authenticate.webhook first; forged 401 test |
| T-02-13 | Tampering/SSRF | JSONL download | high | mitigate | URL only from BulkOperationStatus query over the authenticated client; payload gid merely compared against the shop's recorded gid; unknown gid ignored (tested) |

| T-02-16 | Elevation | cross-shop ingest | high | mitigate | All upserts keyed [shop, gid]; shop from authenticate.webhook or the authenticated session only |
